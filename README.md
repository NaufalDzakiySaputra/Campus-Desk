# Campus Desk

Campus Desk is a desktop application designed to help university students manage their academic activities.

## Features

- Manage tasks and deadlines
- Organize courses and semesters
- Manage study material references
- Back up and restore application data
- Receive desktop reminders for upcoming deadlines

## Installation

Download `CampusDesk-Setup.exe` from the [Releases page](https://github.com/NaufalDzakiySaputra/Campus-Desk/releases).

## Technology

- Python
- PySide6
- SQLite
